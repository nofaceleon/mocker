# MockHub 设计完成总结

## 已完成内容

为 Mock 服务可视化平台（MockHub）完成了完整的 5 页设计系统，全部在 Ardot 编辑器中构建。

### 页面清单

| 页面 | 说明 |
|------|------|
| **项目列表** | 统计卡片（总项目数/Mock 接口数/今日请求/在线服务）+ 项目卡片网格（名称、状态、描述、接口数、请求量、功能组、类型标签） |
| **项目详情** | 项目头部信息 + 功能组折叠列表 + 接口表格（方法标签、路由路径、类型、状态、操作） |
| **接口配置** | 表单布局：基础信息（名称/方法/路径/类型/描述/状态）+ 响应配置（状态码/延迟/Content-Type + 暗色 JSON 编辑器）+ 数据联动 |
| **数据联动** | 联动规则表格（源接口 → 目标接口，含箭头连线、方法标签、联动类型、状态）+ 数据流向可视化占位区 |
| **请求日志** | 日志表格（时间/方法/路径/状态码/响应时间/操作）+ 筛选按钮 + 分页控件 |

### 设计规范

- **风格**：Bento Console Flat Light（清爽浅色工作区）
- **配色**：Bento Neutral 冷色调中性色
- **字体**：Geist + Geist Mono（开发者工具标配）
- **布局**：侧边栏 256px + 主内容区，面包屑导航，统一卡片阴影和边框
