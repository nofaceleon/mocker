设计理念

基于 PRD v1.0 的核心需求，强调数据可视化、操作流畅性和开发者友好。通过可视化界面，让开发者无需编写代码即可完成 Mock 配置工作。

克制黑白灰
纯黑主色 + 高级灰阶，避免视觉疲劳
深度层次
微阴影 + 等宽字体 + JetBrains Mono
数据可视
折线图 + 饼图 + 实时状态指示
精致细节
pulse 动画、dashed 边框、live dot
